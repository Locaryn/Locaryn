Serveur en marche

Locaryn sur {{MACHINE}}

Cette adresse ne s'ouvre pas dans un navigateur : c'est celle que les autres appareils saisissent dans Locaryn pour se servir de ce PC.

Depuis un autre ordinateur

  1. Utiliser seulement le modèle de ce PC : Réglages → Serveur & fonctions → Modèle d'un autre PC, puis saisir {{ADRESSE}}. La conversation, les fichiers et les outils (terminal, MCP comme Roblox Studio) restent sur l'ordinateur où vous écrivez.
  2. Tout faire sur ce PC : Réglages → Serveur & fonctions → Se connecter à un serveur. Les conversations, les projets et les outils sont alors ceux de ce PC.

Depuis un téléphone

Dans l'application Locaryn, scannez le QR code affiché sur ce PC (Réglages → Serveur & fonctions).
