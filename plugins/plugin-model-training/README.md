# Locaryn Plugin: Model Training & LoRA Workbench (`plugin-model-training`)

Official Locaryn extension for managing LoRA adapters, model fine-tuning weights, and quantization precision.

## Features
- **LoRA Adapter Management**: Hot-load and scale `.gguf` LoRA adapters.
- **Model Obliteration**: RepE / Transformer-lens activation steering.

## Installation
```bash
locaryn plugin install Locaryn/plugin-model-training
```
