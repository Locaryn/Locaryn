# Locaryn Plugin: Document RAG & Q&A (`plugin-rag-qa`)

Official Locaryn extension providing Retrieval-Augmented Generation (RAG) over PDF, markdown, and code documents.

## Features
- **Vector Search**: Semantic embedding indexation with chunk citations.
- **Studio Panel**: Directly powered by `RagPanel.tsx`.

## Installation
```bash
locaryn plugin install Locaryn/plugin-rag-qa
```
