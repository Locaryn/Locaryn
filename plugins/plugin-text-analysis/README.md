# Locaryn Plugin: Text Analysis (`plugin-text-analysis`)

Official Locaryn extension for text sentiment analysis, classification, and batch data processing.

## Features
- **Batch Processing**: Compatible with `BatchStudio.tsx`.
- **Studio Tab**: Adds the "Analyse texte" tab in Locaryn Studio.

## Installation
```bash
locaryn plugin install Locaryn/plugin-text-analysis
```
