# Locaryn Plugin: Video Generation (`plugin-video-gen`)

Official Locaryn extension for text-to-video and image-to-video synthesis.

## Features
- **Video Models**: AnimateDiff, Wan2.1, CogVideoX, HunyuanVideo.
- **Studio Integration**: Adds the "Vidéo" tab to Locaryn Studio.

## Installation
```bash
locaryn plugin install Locaryn/plugin-video-gen
```
