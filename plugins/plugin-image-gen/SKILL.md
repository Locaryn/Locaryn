# Image Generation Skill

Use the `generate_image` tool when the user asks to create an image, illustration, logo, or UI mockup.

## Usage
Provide:
- `prompt`: Detailed visual description.
- `width` / `height`: Resolution (default: 1024x1024).
- `model`: Selected local diffusion model.
