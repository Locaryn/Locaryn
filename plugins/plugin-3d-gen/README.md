# Locaryn Plugin: 3D Asset Generation (`plugin-3d-gen`)

Official Locaryn extension for generating 3D models, meshes, and textures from prompts or reference images.

## Features
- **Formats**: Exports to GLTF, GLB, and OBJ.
- **Studio Tab**: Adds the "3D" panel in Locaryn Studio.

## Installation
```bash
locaryn plugin install Locaryn/plugin-3d-gen
```
