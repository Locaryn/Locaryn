# Locaryn Plugin: Image Editor & Inpainting (`plugin-image-editor`)

Official Locaryn extension providing image inpainting, object removal, and region-based canvas editing.

## Features
- **Mask Inpainting**: Regenerate selected areas of an image with precise prompts.
- **Canvas Integration**: Directly integrated with `RegionEditPanel.tsx`.

## Installation
```bash
locaryn plugin install Locaryn/plugin-image-editor
```
