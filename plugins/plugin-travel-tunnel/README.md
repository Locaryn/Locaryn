# Locaryn Plugin: Travel Mode & Tunnels (`plugin-travel-tunnel`)

Official Locaryn extension for launching encrypted outbound tunnels (Cloudflare, ngrok, devtunnel) with QR pairing.

## Features
- **Mobile Pairing**: Scan QR code to connect the Locaryn mobile app from anywhere.
- **Settings Integration**: Adds the "Mode Voyage & Tunnels" tab in Locaryn Settings.

## Installation
```bash
locaryn plugin install Locaryn/plugin-travel-tunnel
```
