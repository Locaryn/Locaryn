# Locaryn Plugin: Machine Translation (`plugin-translation`)

Official Locaryn extension providing translation of documentation, code strings, and text.

## Features
- **Offline Engines**: NLLB-200, MarianMT, Opus-MT.
- **Studio Tab**: Adds the "Traduction" tab in Locaryn Studio.

## Installation
```bash
locaryn plugin install Locaryn/plugin-translation
```
