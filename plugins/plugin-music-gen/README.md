# Locaryn Plugin: Music Generation (`plugin-music-gen`)

Official Locaryn extension for generating instrumental tracks and ambient sound effects from descriptions.

## Features
- **Engines**: MusicGen, AudioCraft, Stable Audio.
- **Studio Tab**: Adds the "Musique" tab in Locaryn Studio.

## Installation
```bash
locaryn plugin install Locaryn/plugin-music-gen
```
