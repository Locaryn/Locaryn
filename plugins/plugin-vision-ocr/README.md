# Locaryn Plugin: Vision & OCR (`plugin-vision-ocr`)

Official Locaryn extension for OCR text extraction and visual object detection.

## Features
- **Models**: Florence-2, GOT-OCR2, YOLO, Qwen2-VL.
- **Studio Tab**: Adds the "Détection & OCR" tab in Locaryn Studio.

## Installation
```bash
locaryn plugin install Locaryn/plugin-vision-ocr
```
